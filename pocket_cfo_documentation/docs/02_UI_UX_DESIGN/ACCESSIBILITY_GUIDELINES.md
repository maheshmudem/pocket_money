# Accessibility Guidelines
- All controls require semantic labels, roles and sensible focus order.
- Support text scaling without clipping totals or hiding actions.
- Validate text and chart contrast in light/dark themes.
- Do not rely on green/red alone; include labels, icons or patterns.
- Provide text summaries for charts and tables.
- Respect reduced-motion preferences.
- Use appropriately sized touch targets; verify platform guidance during design review.
- Support keyboard/focus handling on tablets where applicable.
- Error copy explains the issue and recovery action.
- Localize currency, date, number and plural formatting without changing canonical stored values.

Accessibility is part of each screen's Definition of Done, not a final-only audit.
