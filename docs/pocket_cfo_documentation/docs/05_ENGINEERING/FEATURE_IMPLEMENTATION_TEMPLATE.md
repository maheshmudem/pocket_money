# Feature Implementation Specification Template
Copy this for each feature, e.g. `FEATURE_TRANSACTIONS_001.md`.
```markdown
# FEATURE-<NAME>-### — Feature Name
- Owner / Status / Priority
- Related requirements: FR-###, NFR-###, SEC-###
- Screens: SCR-...
- APIs: API-...
- Database objects: DB-...
- ADRs: ADR-...
## 1. Purpose and user value
## 2. Scope and out-of-scope
## 3. User stories
## 4. Acceptance criteria (Given/When/Then)
## 5. User flow
## 6. UI and all screen states
## 7. Domain entities and business rules
## 8. Use cases
## 9. Repository contracts
## 10. Database/migration impact
## 11. API/synchronization impact
## 12. BLoC/Cubit events and states
## 13. Security/privacy impact
## 14. Error/offline behaviour
## 15. Analytics events (if approved)
## 16. Test plan and test data
## 17. Implementation tasks
## 18. Definition of Done
## 19. Rollout/migration notes
## 20. Open decisions
```
A task is not ready until scope, acceptance criteria, dependencies and data impact are understood.
